## Overview
Ứng dụng Web App giúp giáo viên chấm điểm bài tập (30 học sinh) bằng hệ thống ngôi sao (3-10 sao) và tự động đưa ra lời phê động viên. Học sinh có thể xem bài của nhau để tăng động lực thi đua.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla để tối ưu tốc độ và sự đơn giản cho Newbie).
- **Backend:** Node.js + Express.
- **Database:** SQLite (Dễ cài đặt, phù hợp quy mô 30 học sinh).
- **Lưu trữ:** Thư mục `uploads/` trên server (Ảnh/Video).
